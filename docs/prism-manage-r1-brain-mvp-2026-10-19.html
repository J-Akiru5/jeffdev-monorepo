Summary

The brain now captures work as it happens. Any task discussion can be distilled into a memory entry — one button in the task sheet, AI summary when Gemini is configured, deterministic fallback when it isn't. Agent sessions ingest through a secret-gated endpoint with an opencode hook script. The /brain surface gained source filters and realtime updates. Auto-distillation on comment is available behind BRAIN_AUTO_DISTILL=1 — off by default while the spike awaits its GO verdict.

How to Use It

# Save a discussion: open any task with comments → "Save to Brain"
# Flip on auto-distillation (optional):  BRAIN_AUTO_DISTILL=1
# Ingest an agent session:
node scripts/opencode-brain-hook.mjs \
  --workspace <uuid> --title "Session: …" --file transcript.txt
# (env: BRAIN_INGEST_URL, BRAIN_INGEST_SECRET)

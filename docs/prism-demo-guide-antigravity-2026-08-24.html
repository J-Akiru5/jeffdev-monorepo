Governance over Generation: the Antigravity run

docs/prism-demo-guide-antigravity-2026-08-24.html - one folder, one IDE, one sentence

The arc. We never state a hex code. We ask the agent for a button "based on our design constitution" - and Prism does the rest: either the agent reads the constitution and complies on the first write, or it guesses, and the Pass intercepts the write and forces self-correction. Both outcomes are the product. This guide scripts both branches so nothing live can surprise you.

0Pre-flight - one time, in Antigravity's terminal

# folder already open + npm install done (your current state)
mkdir styles
(echo :root { & echo   --brand-primary: #06b6d4; & echo   --text-main: #0a0a0a; & echo   --brand-danger: #ef4444; & echo }) > styles\globals.css

npx prism init --yes
dir .prism     :: constitution
dir .agents    :: antigravity hook (Pass wired)

The --brand-danger token is deliberate: it powers Act II without you ever naming a hex.

1ACT I - the constitution prompt

Paste into the Antigravity agent chat
"Please make a Button component based on our design constitution."

That is the entire prompt. No hex, no file path, no framework. The word constitution is doing the work - it tells the agent governance exists, and Prism decides what happens next.

Branch A - the agent complies on first write

What you say while it writes

"Notice what just happened. Nobody told it a color. It opened our constitution, found the design tokens, and wrote var(--brand-primary) on the first attempt. That is governance guiding generation - before any review, before any PR."

Then go straight to Act II for the enforcement beat.

Branch B - the agent guesses (raw hex appears)

What you say while the Pass fires

"And here is the moment that sells it. The agent didn't know our palette - it guessed a hex. Watch the write get intercepted: exit code 2, a named file, a line number, and the exact replacement. The agent is now fixing itself. No reviewer. No PR. No tomorrow."

Both branches converge: the file on disk ends up token-clean. type src\Button.tsx to prove it.

2ACT II - the enforcement beat (guaranteed violation)

Branch A agents that complied once may comply again - so force the test with a request the constitution constrains but the agent cannot look up:

Follow-up prompt
"Great. Now add a Danger variant to the Button - use our brand red for it."

"Our brand red" is unknowable unless the agent re-reads the constitution. If it hardcodes #ef4444 or red, the Pass flags it and demands var(--brand-danger). If it checks the constitution first - say so: "it learned. The correction from thirty seconds ago is now baked into its behavior."

3Receipts - close the loop deterministically

npx prism check src\Button.tsx
:: "no violations found"  (or lists remaining warns, none blocking)

type src\Button.tsx

Final line for mentors: "This file is the entire product. A versioned constitution that any agent, any IDE, and any CI pipeline can read and enforce - today Claude Code, Cursor, and Antigravity. Tomorrow, whatever ships next."

5Mentor quick-card (BMC / market / infra)

"Why pay when Cursor/Claude have free rules files?"Rules files suggest. Prism enforces - in-loop, cross-agent, with tokens, sync, and audit. One constitution, every tool.

"Competitors?"Native rules files (suggestions), CodeRabbit/Greptile (post-hoc PR review), SonarQube/ESLint (CI linters). Nobody enforces at write-time across agents. In-house grep scripts are the real Phase-0 competitor - we're the productized version.

"Vendor lock?"Open-source engine, AGPL core + MIT-facing CLI. The constitution is a plain JSON file users own.

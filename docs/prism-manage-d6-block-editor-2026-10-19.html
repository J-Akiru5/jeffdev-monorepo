D6 — Pages Block Editor

2026-10-19 Branch: feat/pm-d6-block-editor → PR → develop Complete

Summary

Pages are now a real block editor. Six block types — text, heading, bullet, checklist, code, divider — with Enter-to-create, Backspace-to- delete, per-block type menus, reorder/delete controls, and an 800ms debounced autosave. Existing pages open unchanged (legacy content maps on load).

Interaction Model

  • Enter creates a block below (lists stay lists); Backspace on an empty block removes it and focuses the previous one; Shift+Enter is a line break.
  • Every block has a type menu (left icon, hover), plus move/delete controls — keyboard reachable, visible on focus.
  • Checklists toggle with strikethrough; code renders monospace in a panel; dividers are a rule.

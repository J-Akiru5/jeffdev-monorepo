Recurring Tasks

2026-10-19 Repo: jeffdev-monorepo Agent: opencode · DeepSeek V4.1 Flash (autonomous overnight) Branch: feat/pm-recurring-tasks → PR → develop Complete — CI green

Summary

Tasks can now repeat — daily, weekly, or monthly. Set "Repeat" in the task sheet; when an occurrence is completed, the next one is spawned automatically with the due date advanced (and the same recurrence), so standing chores like weekly reviews never fall off the board. One pending occurrence at a time — re-saving or re-completing never duplicates.

How It Works

PieceDetail
Schematasks.recurrence (daily/weekly/monthly, nullable) + recurrence_source_id linking spawned occurrences to their origin (indexed). Migration 20261019000002, applied live.
Date enginelib/recurrence.ts — pure nextOccurrenceDate() (5 unit tests). Past-due bases measure from "now" so a neglected task doesn't spawn a chain of overdue occurrences.
SpawnspawnNextOccurrence() runs on every completion path — the list checkbox, kanban status moves, and the sheet's Save Changes. Copies title, type, priority, notes, assignee, list, workspace, department; new due date; status backlog.
UI"Repeat" select in the task sheet; a recurrence badge (e.g. Weekly) in the task row's meta line.

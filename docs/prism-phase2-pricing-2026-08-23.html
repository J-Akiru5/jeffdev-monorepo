Summary. Phase 2 implements the roadmap's structural pricing fix end to end. The tier model now matches the product philosophy — Free is genuinely free forever (unlimited local rules and enforcement, one synced project, a 25-generation AI taste), and what costs us money gets priced (Pro ₱299/~$8 with unlimited synced projects and the Kitchen, Team ₱249/seat min 3, Enterprise custom). Regional pricing ships: PH visitors see pesos via Vercel geo detection, everyone else USD, with URL/header overrides for testing and previews. The dead-ended Upgrade button finally reaches real money — it drives PayPal Subscriptions through the env-driven plan-ID flow that already existed server-side but was never connected to any UI, sandbox-first by decision. One latent product bug died in passing: under the old model Free had zero API keys, which made prism pull impossible exactly where the model promised a synced project.

Regional pricing — src/lib/currency.ts

getVisitorCurrency(): Vercel geo header (x-vercel-ip-country === "PH" → pesos) with two override layers — ?currency=PHP|USD URL param wins over geo, x-prism-currency header exists for tests/admin previews. Both the public /pricing page and the dashboard subscription page render through formatMonthlyPrice().

Checkout — the flow that already existed, finally plugged in

Subscription card [Subscribe monthly] / [Annual — 2 months free]
  → POST /api/subscriptions {tier, billing}          (existing endpoint)
  → PayPal /v1/billing/subscriptions {plan_id from env, custom_id: userId}
  → redirect to approval URL
  → buyer approves → returns to /subscription/success?subscription_id=…
  → success page polls /api/subscription-status (never trusts URL params)
  → BILLING.SUBSCRIPTION.ACTIVATED webhook flips prism_subscriptions
    (consolidated verified+idempotent handler from Phase 1)
  • Fixed: success page read camelCase subscriptionId; PayPal sends snake_case subscription_id. Now accepts both.
  • Fixed: /api/subscriptions GET hardcoded the dead 5/3/10 free limits; derives from TIER_LIMITS.
  • Old GET /api/subscriptions/checkout stub left untouched for dev-mode direct activation in development.

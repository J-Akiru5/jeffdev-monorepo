Arc 3 — "Daily Driver"

2026-10-19 Prepared by opencode · DeepSeek V4.1 Flash Status: awaiting GO / priority tweaks Proposed

Goal

Make prism-manage the default daily tool for the founder and the team — faster capture, deeper workflow, compounding knowledge — without regressing the quality bar (30 E2E tests, drift guard, coverage ratchet, RLS suite, all CI-enforced).

Phases

#PhaseScopeSize
D1Task templatesWorkspace-scoped templates (name, type, priority, description, tags, default list); "Save as template" from the sheet; "Start from template" picker fills create flows; E2E.0.5–1 session
D2Bulk actionsMulti-select in list/table; bulk move list, status, priority, assign, complete, delete — routed through the existing RBAC-checked actions; E2E with seeded tasks.0.5–1
D3GitHub webhook reverse-syncPOST /api/github/webhook with HMAC verification (fail-closed); issues.closed/reopened/labeled → task updates; mapper unit tests; rejection E2E; wiring docs.1
D4Task dependenciestask_dependencies (blocker → blocked) with cycle prevention + RLS; sheet "Blocked by" section; Blocked badge + filter; E2E.1
D5Brain context digest (if GO)"Related memories" panel in the task sheet — semantic lookup on the task, top 3 with similarity; E2E.0.5–1
D6Pages block editor (big bet — explicit GO)Structured blocks (heading/text/checklist/code/divider), drag-reorder, autosave.2–3
D7Brain R2 (if GO)Review queue, memory detail/edit/archive; distillation spend logging + caps; ingestion limits.1–2

Sequencing

  • D1 → D2 → D3 → D4 → (D5 if GO) → (D7 if GO) → (D6 on request). Capture velocity first, then workflow depth, then knowledge; the big bet last.
  • Each phase ships standalone: branch → PR → CI green → HTML report. Migrations additive + drift-checked. Stopping after any phase is safe.

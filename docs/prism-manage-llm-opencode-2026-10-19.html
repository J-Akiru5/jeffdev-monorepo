Summary

The brain's LLM calls (thread distillation + ask-the-brain answers) now go through a provider layer that prefers the OpenCode inference API — the same OpenAI-compatible gateway your Go subscription serves (deepseek-v4.1-flash by default). Gemini becomes the fallback, and the deterministic thread-mode summary stays as the last resort. Provider selection is env-driven: flipping to a different key or endpoint is a config change, not a code change.

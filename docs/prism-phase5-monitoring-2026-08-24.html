03Sentry fixes

  • sentry-config withSentry: added authToken passthrough (releases + source maps); migrated deprecated disableLogger/reactComponentAnnotation to webpack.treeshake.removeDebugLogging / webpack.reactComponentAnnotation. Build output now has ZERO deprecation warnings.
  • turbo.json: already passes SENTRY_* wildcard - the variable simply was never set in deploy envs. Jeff action item below.
  • logError(scope, ...args) helper (src/lib/log-error.ts): variadic to mirror console.error call shapes verbatim; first Error arg becomes the captured exception; strings join the message; plain objects become extra context; console output preserved exactly; Sentry no-op without DSN.
  • Sweep: all 56 sites converted across API routes, libs (deepseek/gemini/pricing-db/ai-router), dashboard error boundaries, client components. Tests + dev-noise excluded by design.

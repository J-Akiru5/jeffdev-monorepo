🔌 IDE Connection Guide

How the IDE Connects to Prism

The complete command guide — what to type, when to type it, and why. With every single command explained.

01 The Big Insight

The IDE Does NOT Connect to the Website

This is the most important thing to understand.

💡 How it actually works

The IDE connects to a tiny program called "prism serve" running silently in the background on your computer. This program reads rules from the cloud database and feeds them to the AI. You only run commands ONCE during setup. After that, your IDE handles everything automatically — every time you open it.

🔄 The Simple Loop

You create rules on the website → rules save to the database → IDE opens → prism serve starts automatically → AI asks for rules → prism serve reads database → AI gets the rules → AI writes better code ✅

03 What prism init Writes

The Config Files

When you run prism init, it detects which IDEs you have installed and writes one of these files automatically. You never have to write these by hand.

⚡ Cursor ~/.cursor/mcp.json 
{
  "mcpServers": {
    "prism": {
      "command": "prism",
      "args": ["serve"],
      "env": {

  }
}

04 First-Time Setup

The 6 Steps (Do These Once)

Click a command to copy it to your clipboard.

1
Install the CLI tool
This gives you the prism command globally on your computer
npm install -g prism-context-engine
2
Log in to your account
Connects your terminal session to your Prism account
prism login
3
Download your rules
Copies all your rules from the cloud to your computer so the IDE can use them offline too
prism sync
4
Configure your IDE
Detects which IDEs you have and writes the config files automatically
prism init
5
Restart your IDE
Close and reopen your IDE so it reads the new config file that prism init just wrote
6
Verify everything works
Runs 10 health checks and tells you exactly what's working or broken
prism doctor
✅ Test it works

After setup, open your IDE and ask the AI: "What are my project rules?" — if Prism is connected, the AI will list your rules instead of saying it doesn't know.

05 All Commands

Every Command Explained

Click any group to expand it. Click any command to copy it.

🚀 Setup — Run These Once 4 commands ▼
npm install -g prism-context-engine
Installs the prism command on your computer
When: Once, the very first time
prism login
Connects your terminal to your Prism account
When: Once, after installing
prism sync
Downloads all your rules from the cloud to your computer
When: Once at setup, then whenever new rules are added
prism init
Auto-detects your IDE and writes the config files — no manual editing needed
When: Once per computer
🩺 Health Checks — Is Everything Working? 2 commands ▼
prism doctor
Runs 10 checks (Node version, login, rules cached, dashboard reachable, IDE config found) and shows fix instructions for anything broken
When: Something isn't working
prism status
Quick snapshot — are you logged in? how many rules? is the server reachable?
When: You just want a quick health overview
📋 Rules — Manage Your Rules 6 commands ▼
prism rules list
Show all your rules
prism rules list --category styling
Show only styling rules (categories: architecture, styling, security, performance, testing, documentation, custom)
prism rules list --project my-app
Show rules for one specific project only
prism rules create
Create a new rule (interactive)
prism rules edit <id>
Edit an existing rule by its ID (get the ID from prism rules list)
prism rules delete <id>
Delete a rule permanently
📁 Projects — Manage Your Projects 4 commands ▼
prism projects list
Show all your projects
prism projects view my-app
See all details of one specific project
prism projects create
Create a new project (interactive)
prism projects delete my-app
Delete a project and all its rules
🤖 Auto-Generate Rules — The Power Features 3 commands ▼
prism connect --url http://localhost:3000
Scans a live website using AI — auto-generates 15–25 rules from its design (colors, fonts, spacing, components). Start your dev server first.
Best option for new projects
prism sync --repo ./
Scans your code files, finds naming patterns, import styles, config files — auto-generates rules from them
Good for existing codebases
prism generate --prompt "a card component"
AI generates a full React component that matches your design system and rules
🎨 Brand Profiles — Export Rules for Different Formats 5 commands ▼
prism brands list
See all your brand profiles
prism brands create
Create a brand profile (colors, fonts, voice — interactive wizard)
prism brands export my-brand --format cursor
Export as .cursorrules file for Cursor IDE
prism brands export my-brand --format windsurf
Export as .windsurfrules file for Windsurf IDE
prism brands export my-brand --format claude
Export as CLAUDE.md for Claude Desktop
🔑 API Keys — Manage Authentication Keys 3 commands ▼
prism api-keys list
Show all your API keys (you can also do this on the dashboard website)
prism api-keys create
Generate a new API key (used to authenticate the MCP server)
prism api-keys revoke <id>
Delete an API key permanently (if it was leaked or no longer needed)
📊 Analytics & Optimization — See How It's Being Used 6 commands ▼
prism analytics
See how many times AI called Prism, how many tokens were used, which tools were called most
prism telemetry
Detailed token usage breakdown per rule and tool
prism kitchen analyze --task "build a button"
Preview which rules the AI would receive for a specific task — before the AI even asks
prism kitchen preview
See the exact text string that would be sent to the AI assistant
prism kitchen trim --budget 2000
Automatically shrink rules to fit within a token budget (useful for cheaper AI models)
prism kitchen optimize
Re-rank rules based on which ones actually get used most by the AI
⚙️ Advanced — Manual & Offline Control 4 commands ▼
prism serve
Manually start the MCP server (normally auto-started by IDE — only use for debugging)
prism serve --offline
Start the MCP server using only local cached rules — works with no internet connection
prism marketplace list
Browse community-shared rule sets you can install
prism marketplace install <id>
Install a community rule set into your project

# Prism Context Engine

**Операционная система контекста для Vibecoders** — Устраните «загрязнение контекста», оркестрируя поток правил, дизайн-систем и технологических стеков между облаком и локальными AI-агентами.

## Что такое Prism Context Engine?

Prism Context Engine — это полноценная платформа **управления контекстом на базе ИИ**, которая:

1. **Извлекает правила из видео** — загружайте записи экрана, автоматически извлекайте архитектурные паттерны с помощью Azure OpenAI
2. **Применяет стандарты** — развертывайте правила для AI-ассистентов кодирования через MCP (Model Context Protocol)
3. **Обеспечивает семантический поиск** — находите релевантные архитектурные обсуждения с помощью векторных эмбеддингов

### Основная метафора

| Концепция | Эквивалент Prism | Описание |
|---------|------------------|-------------|
| 🍳 **Кухня** | SaaS Панель управления | Где «Шеф-повар» (Разработчик) смешивает ингредиенты (Next.js, Tailwind, Glassmorphism) |
| 📜 **Рецепт** | Правила контекста | Выходной файл (например, `.cursorrules`), содержащий строгие инструкции |
| 🍽️ **Официант** | Протокол MCP | Доставляет свежий Рецепт прямо к столу IDE |

### Извлечение контекста из видео

**Автоматизированная документация**: Загрузите запись экрана вашего рабочего процесса разработки. Prism анализирует транскрипт видео с помощью Azure OpenAI, чтобы автоматически извлекать архитектурные правила, паттерны кодирования и лучшие практики в действенный контекст, понятный вашему AI-ассистенту кодирования.

Работает с:
- **Cursor** ✅
- **Windsurf** ✅
- **Claude (через MCP)** ✅
- **VS Code** (через расширение MCP)
- **GitHub Copilot** (скоро)

Вместо того чтобы надеяться, что ваш ИИ будет следовать лучшим практикам, **Prism заставляет их соблюдать**.

## Быстрый старт

### Вариант A: Веб-панель (Рекомендуется)

```bash
# 1. Зарегистрируйтесь в веб-панели
https://prism.jeffdev.studio/sign-up

# 2. Создайте свой первый проект и профиль бренда
# 3. Загрузите видео или создайте правила вручную
# 4. Экспортируйте файл .cursorrules и вставьте в свой проект
```

### Вариант B: MCP Сервер (Для продвинутых)

Для синхронизации в реальном времени с вашей IDE:

```bash
# 1. Установите MCP сервер глобально
npm install -g @prism/mcp-server

# 2. Настройте вашу IDE (Cursor/Windsurf/VS Code)
# Добавьте в настройки MCP:
{
  "mcpServers": {
    "prism": {
      "command": "prism-mcp",
      "args": ["--api-key", "ВАШ_API_КЛЮЧ"]
    }
  }
}

# 3. Ваш AI-ассистент теперь имеет прямой доступ к вашим правилам
```

## Что отличает Prism?

### 🎥 Видео-ориентированный захват контекста
Записывайте экран во время обсуждения архитектуры. Prism автоматически извлекает правила из ваших объяснений.

### 🧠 Извлечение правил на основе ИИ
GPT-4o-mini анализирует транскрипты для выявления:
- Архитектурных паттернов
- Соглашений о стиле кода
- Правил именования
- Стратегий тестирования
- Практик безопасности

### 🔍 Семантический поиск
Векторные эмбеддинги позволяют находить релевантные архитектурные обсуждения, а не просто соответствие ключевым словам.

### 🚀 Интеграция MCP без настройки
`npx prism connect` — и готово. Ваш AI-ассистент теперь имеет контекст.

## Пример из реального мира

```typescript
// До Prism: Общий код
const data = await fetch('/api/users');

// После Prism: Применение ваших стандартов
const { data, error } = await api.users.list();
if (error) {
  toast.error(error.message);
  return;
}
```

Ваш AI-ассистент учится из ваших видео:
- Вы используете пользовательскую обертку API с обработкой ошибок
- Вы показываете ошибки через toast-уведомления
- Вы следуете паттерну раннего возврата

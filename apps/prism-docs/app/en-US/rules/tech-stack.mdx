# Tech Stack Rules

Infrastructure and framework constraints.

## Core Stack Protocol

```
Category: architecture
Priority: 2
Tags: stack, backend, framework, infrastructure
```

### Framework

| Layer | Technology | Version |
|-------|------------|---------|
| Frontend | Next.js (App Router) | 16.x |
| UI Library | React | 19.x |
| Runtime | Node.js (LTS) | 20.x |
| Package Manager | npm | 10.x |

### Data Layer

| Use Case | Technology |
|----------|------------|
| Prism dashboard data | Supabase Postgres (via `@syntaxure-labs/db/prism`) |
| Prism dashboard auth | Supabase Auth |
| Dashboard hosting | Vercel |
| Rate Limiting | Upstash Redis |

### AI Stack

- **Semantic check layer (CLI, opt-in)**: Gemini (`gemini-3.6-flash` default)
- **MCP server AI tools**: Gemini by default (`AI_PROVIDER` in `apps/prism-mcp-server`), Azure OpenAI as an opt-in fallback
- **Dashboard AI features**: Gemini (`GOOGLE_GEMINI_API_KEY`)

### Frontend Engineering

- **Styling**: Tailwind CSS v4 + clsx + tailwind-merge
- **Motion**: framer-motion + gsap + @studio-freight/lenis
- **Validation**: Zod (mandatory for all forms & APIs)
- **Auth**: Clerk (Prism), Firebase Auth (Agency)

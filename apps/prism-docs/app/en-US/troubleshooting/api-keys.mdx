# API Keys

Create and use API keys for dashboard sync (`prism pull`) and the REST API.

## Create a key

In the dashboard: **Settings** → **API Keys** → generate. Copy it immediately — keys are stored hashed and cannot be shown again.

Or with the CLI (requires `prism login`):

```bash
prism api-keys create
prism api-keys list
prism api-keys revoke <id> --force
```

## Use a key

```bash
# CLI: sync your team's rules (fails safe on any error)
export PRISM_API_KEY=your_key_here
prism pull
```

Or store it in the project config instead of the environment:

```json
// .prism/config.json
{
  "apiKey": "your_key_here"
}
```

REST API:

```bash
curl https://prism.syntaxure.dev/api/v1/projects \
  -H "x-api-key: your_key_here"
```

## Troubleshooting

### `prism pull` says no API key found

The command checks `PRISM_API_KEY` and `.prism/config.json` (in that order). Set one of them.

### 401 Invalid API key

1. The key was revoked — generate a new one
2. Trailing whitespace when copying — re-copy from the dashboard
3. Wrong header for REST calls — the API uses `x-api-key`, not `Authorization: Bearer`

### Key limits

Key count is capped per plan (Free: 1, Pro: 3, Team: 10). `prism api-keys create` fails at the cap; revoke an unused key or upgrade. See [Pricing](/pricing).

### Revoking a key

```bash
prism api-keys revoke <id>
```

Revocation takes effect immediately; the hash stops matching on the next request.

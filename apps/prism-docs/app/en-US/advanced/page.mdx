## Semantic check layer (local, opt-in)

`prism check` can add a Gemini-powered intent-level check on top of the deterministic engine. It runs only when you set `PRISM_GEMINI_CHECK=1` and provide `GEMINI_API_KEY` or `GOOGLE_GEMINI_API_KEY`, is hard-capped at 12 seconds, and fails open. See [Hooks and IDE Setup](/integrations).

The hosted semantic search page is [deprecated](/advanced/semantic-search) — the dashboard API has no vector search endpoints today.

## Brand Profiles

Create reusable design system profiles that define:
- **Colors** - Primary, secondary, accent colors with hex values
- **Typography** - Font families, sizes, weights
- **Spacing** - Margin and padding scales
- **Components** - Button styles, card designs, form elements

Export profiles as CSS variables, Tailwind config, or include them in your context rules.

## API Access

Build custom integrations with the dashboard REST API (`/api/v1/...`):
- Projects, rules, brands, components, skills
- API keys and analytics
- Marketplace listing

See the [API Reference](/advanced/api-reference).

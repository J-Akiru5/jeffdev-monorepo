# Claude Desktop Integration

Claude Desktop works with Prism through MCP only.

<Callout type="info">
  Claude Desktop has no hooks system. It gets MCP (advisory rules) — the
  assistant can read your rules, but no write is blocked. Blocking
  enforcement is available in Claude Code; see [Hooks and IDE Setup](/integrations).
</Callout>

## Setup

```bash
# One command detects Claude Desktop and writes its MCP config
prism ide-setup
```

The file it writes (macOS path from source):

```
~/Library/Application Support/Claude/claude_desktop_config.json
```

```json
{
  "mcpServers": {
    "prism": {
      "command": "npx",
      "args": ["@prism-engine/cli", "serve"],
      "env": { "PRISM_TOKEN": "<your token>" }
    }
  }
}
```

`prism ide-setup` merges into the existing config — it does not overwrite other servers. If the existing file is invalid JSON, it is left untouched (the entry is skipped).

## Verify

```bash
prism doctor
```

`prism doctor` reports Claude Desktop as configured when its config has a `prism` MCP server entry. Restart Claude Desktop after setup.

# Windsurf Integration

Prism works in Windsurf through MCP. Windsurf has no hook system, so enforcement runs as advisory rules through the assistant.

## Setup

```bash
# One command detects Windsurf and writes ~/.windsurf/mcp.json
prism ide-setup
```

The config it writes:

```json
{
  "mcpServers": {
    "prism": {
      "command": "npx",
      "args": ["@prism-engine/cli", "serve"],
      "env": { "PRISM_TOKEN": "<your token>" }
    }
  }
}
```

`prism ide-setup` asks for `prism login` first, or you can set `PRISM_TOKEN`. It asks before touching any IDE config.

`prism serve` starts the MCP server (stdio). It falls back to a built-in lite server reading the local cache when the full `prism-mcp-server` is unavailable. Run `prism sync` to pre-cache rules.

## Verify

```bash
prism doctor
```

Restart Windsurf after setup.

## Local enforcement

MCP in Windsurf is advisory — the assistant reads your rules but nothing blocks a write. For blocking enforcement in this repository's supported agents, see [Hooks and IDE Setup](/integrations) (Claude Code, Cursor, Antigravity). You can also always run the linter by hand:

```bash
prism check src/App.tsx
```

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Prism not listed | Validate `~/.windsurf/mcp.json` is valid JSON; restart Windsurf |
| Empty rule responses | Run `prism sync` to populate the local cache |
| No token | Run `prism login` or set `PRISM_TOKEN` |

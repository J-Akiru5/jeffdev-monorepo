# Cursor Integration

Prism works in Cursor two ways: **hook enforcement** (checks every write) and **MCP** (rules available to the assistant). Both are wired by the CLI.

## Hook enforcement (recommended)

`prism init` writes a Cursor hook into `.cursor/hooks.json`:

```json
{
  "version": 1,
  "hooks": {
    "afterFileEdit": [
      { "command": "npx @prism-engine/cli check --hook --format cursor" }
    ]
  }
}
```

After each file edit, Cursor runs the command with the edit payload on stdin. On a blocking violation, the command exits 2 with a correction message and Cursor feeds it back to the model.

<Callout type="warning">
  Cursor can also auto-map `.claude/settings.json` hooks when third-party
  skill mapping is enabled. Running both surfaces produces duplicate
  corrections — pick one.
</Callout>

Config note: the hook schema is verified against Cursor's public docs, but end-to-end firing inside Cursor has not been exercised on every machine. If corrections do not appear, run `prism check <file>` manually to confirm your rules file works.

## MCP setup

```bash
# One command detects Cursor and writes ~/.cursor/mcp.json
prism ide-setup
```

The config it writes:

```json
{
  "mcpServers": {
    "prism": {
      "command": "npx",
      "args": ["@prism-engine/cli", "serve"],
      "env": { "PRISM_TOKEN": "<your token>" }
    }
  }
}
```

`prism serve` starts the MCP server (stdio). It uses the full `prism-mcp-server` when available and falls back to a built-in lite server reading the local cache (`~/.prism/rules/rules.json`). Run `prism sync` to populate the cache for offline use.

If you are not signed in, `prism ide-setup` offers to continue without a token (MCP advisory mode).

## Verify

```bash
prism doctor
```

`prism doctor` checks auth, rules, cache, and IDE configuration, and reports Cursor as configured when `~/.cursor/mcp.json` has a `prism` server entry.

Restart Cursor completely after setup.

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Prism not in MCP list | Validate `~/.cursor/mcp.json` is valid JSON; restart Cursor fully |
| Hook never fires | Check `.cursor/hooks.json`; confirm `.prism/rules.json` exists; check `.prism/activity.log` |
| Duplicate corrections | Remove either the Cursor hook or the Claude-mapped hooks |
| `npx` timeout on first call | Pre-fetch: `npx @prism-engine/cli --version` |

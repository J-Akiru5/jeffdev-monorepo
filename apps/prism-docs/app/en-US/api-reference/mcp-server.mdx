# MCP Server

The MCP server gives AI assistants tools for reading and enforcing your rules over the Model Context Protocol (stdio transport).

## How it runs

You do not install the MCP server separately. `prism serve` starts it:

```bash
prism serve            # try full server, fall back to local cache
prism serve --offline  # local cache only
```

`prism serve` attempts to spawn the full `prism-mcp-server` (from this repository) and falls back to a built-in lite server that reads the local cache at `~/.prism/rules/rules.json`. Run `prism sync` to populate the cache.

`prism ide-setup` writes the IDE configuration:

```json
{
  "mcpServers": {
    "prism": {
      "command": "npx",
      "args": ["@prism-engine/cli", "serve"],
      "env": { "PRISM_TOKEN": "<your token>" }
    }
  }
}
```

## Tools

These are the tools registered by the server (`apps/prism-mcp-server/src/index.ts`):

| Tool | Purpose |
|------|---------|
| `get_architectural_rules` | Retrieve active architectural rules |
| `validate_code_pattern` | Validate a code snippet against active rules |
| `prism_scan` | Scan content against rules |
| `get_skill` | Get a skill by id |
| `list_skills` | List available skills |
| `prism_check` | Check files against rules |
| `prism_fix` | Propose fixes for violations |
| `repo_extract` | Extract rules from a repository (AI-assisted) |
| `repo_scan` | Scan a repository for conventions |
| `prism_kitchen` | Context budget operations |
| `prism_intercept` | Intercept and evaluate a proposed change |
| `prism_health` | Health check (reports database, AI provider, ranking status) |
| `prism_compile` | Compile rules |
| `prism_orchestrate` | Orchestrate a multi-step task (AI) |
| `prism_memory` | Governance memory |
| `prism_drip` | Incremental rule delivery |

## AI providers

The server's AI-assisted tools route through an AI provider. The router default is Gemini (`AI_PROVIDER` defaults to `gemini` in `apps/prism-mcp-server/src/lib/ai-router.ts`), configured with `GOOGLE_GEMINI_API_KEY` or `GEMINI_API_KEY`. An Azure OpenAI path still exists in the code as an opt-in fallback when Gemini credentials are absent — it is not the default.

## Plan gating

The dashboard API gates MCP access by subscription tier: free tier has no MCP sync; Pro and above include it. See [Pricing](/pricing). Local enforcement (`prism check`, hooks) is never gated.

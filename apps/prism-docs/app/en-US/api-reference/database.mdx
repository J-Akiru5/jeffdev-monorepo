# Database API

<Callout type="info">
  This page documents an internal workspace package, not a published npm
  package. It is kept for contributors to this repository.
</Callout>

The `@syntaxure-labs/db` workspace package provides database access for the apps in this monorepo.

## Prism tables (Supabase Postgres)

Prism's data lives in the shared Supabase Postgres project, in `prism_*` tables (for example `prism_projects`, `prism_rules`, `prism_subscriptions`, `prism_api_keys`). Access goes through a service-role client; each API route does its own user authorization.

```typescript
import { getPrismDb } from "@syntaxure-labs/db/prism";

const db = getPrismDb();
const { data } = await db
  .from("prism_rules")
  .select("*")
  .eq("created_by", userId);
```

IDs are Postgres UUIDs. `isValidId()` from the same module validates them.

This replaced the earlier Azure Cosmos DB (MongoDB API) store. See `docs/prism/PRISM_MIGRATION.md` in the repository for the migration writeup.

## Environment variables

| Variable | Description |
|----------|-------------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Public anon key |
| `SUPABASE_SERVICE_ROLE_KEY` | Service-role key (server only; powers `getPrismDb()`) |

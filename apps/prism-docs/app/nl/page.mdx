# Prism Context Engine

**Het Context Besturingssysteem voor Vibecoders** — Elimineer "Contextvervuiling" door de stroom van regels, designsystemen en technische stacks tussen de Cloud en lokale AI-agenten te orkestreren.

## Wat is Prism Context Engine?

Prism Context Engine is een compleet **AI-aangedreven contextbeheerplatform** dat:

1. **Regels uit Video Haalt** - Upload schermopnames, haal automatisch architectuurpatronen eruit met Azure OpenAI
2. **Standaarden Afdwingt** - Implementeer regels naar AI-codeerassistenten via MCP (Model Context Protocol)
3. **Semantisch Zoeken Mogelijk Maakt** - Vind relevante architectuurdiscussies met behulp van vector-embeddings

### De Kernmetafoor

| Concept | Prism Equivalent | Beschrijving |
|---------|------------------|-------------|
| 🍳 **De Keuken** | SaaS Dashboard | Waar de "Chef" (Ontwikkelaar) ingrediënten mixt (Next.js, Tailwind, Glassmorphism) |
| 📜 **Het Recept** | Contextregels | Het uitvoerbestand (bijv. `.cursorrules`) met strikte instructies |
| 🍽️ **De Ober** | MCP Protocol | Levert het verse Recept direct aan de IDE-tafel |

### Video-naar-Context Extractie

**Geautomatiseerde Documentatie**: Upload een schermopname van je ontwikkelworkflow. Prism analyseert het videotranscript met Azure OpenAI om automatisch architectuurregels, codeerpatronen en best practices te extraheren naar bruikbare context die je AI-codeerassistent kan begrijpen.

Werkt met:
- **Cursor** ✅
- **Windsurf** ✅
- **Claude (via MCP)** ✅
- **VS Code** (via MCP-extensie)
- **GitHub Copilot** (binnenkort)

In plaats van te hopen dat je AI best practices volgt, **dwingt Prism ze af**.

## Snel starten

### Optie A: Web Dashboard (Aanbevolen)

```bash
# 1. Meld je aan via het web dashboard
https://prism.syntaxure.dev/sign-up

# 2. Maak je eerste project en merkprofiel
# 3. Upload een video of maak handmatig regels aan
# 4. Exporteer het .cursorrules-bestand en plak het in je project
```

### Optie B: MCP Server (Geavanceerd)

Voor real-time synchronisatie met je IDE:

```bash
# 1. Installeer de MCP-server globaal
npm install -g @prism/mcp-server

# 2. Configureer je IDE (Cursor/Windsurf/VS Code)
# Voeg toe aan je MCP-instellingen:
{
  "mcpServers": {
    "prism": {
      "command": "prism-mcp",
      "args": ["--api-key", "JOUW_API_SLEUTEL"]
    }
  }
}

# 3. Je AI-assistent heeft nu live toegang tot je regels
```

## Wat Maakt Prism Anders?

### 🎥 Video-Eerste Contextvastlegging
Neem je scherm op terwijl je architectuur bespreekt. Prism haalt automatisch regels uit je uitleg.

### 🧠 AI-aangedreven Regels Extractie
GPT-4o-mini analyseert transcripties om te identificeren:
- Architectuurpatronen
- Codestijlconventies
- Naamgevingsregels
- Teststrategieën
- Beveiligingspraktijken

### 🔍 Semantisch Zoeken
Vector-embeddings maken het mogelijk om relevante architectuurdiscussies te vinden, niet alleen trefwoordovereenkomsten.

### 🚀 Zero-Config MCP-integratie
`npx prism connect` en je bent klaar. Je AI-assistent heeft nu context.

## Voorbeeld uit de Praktijk

```typescript
// Vóór Prism: Generieke code
const data = await fetch('/api/users');

// Na Prism: Dwingt jouw standaarden af
const { data, error } = await api.users.list();
if (error) {
  toast.error(error.message);
  return;
}
```

Je AI-assistent leert van je video's dat jij:
- Een custom API-wrapper gebruikt met foutafhandeling
- Fouten laat zien via toast-meldingen
- Early return-patronen volgt

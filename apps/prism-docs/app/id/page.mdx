# Prism Context Engine

**Sistem Operasi Konteks untuk Vibecoder** — Hilangkan "Polusi Konteks" dengan mengatur aliran aturan, sistem desain, dan tumpukan teknologi antara Cloud dan Agen AI lokal.

## Apa itu Prism Context Engine?

Prism Context Engine adalah platform **tata kelola konteks bertenaga AI** lengkap yang:

1. **Mengekstrak Aturan dari Video** - Unggah rekaman layar, ekstrak pola arsitektur secara otomatis menggunakan Azure OpenAI
2. **Menerapkan Standar** - Terapkan aturan ke asisten coding AI melalui MCP (Model Context Protocol)
3. **Memungkinkan Pencarian Semantik** - Temukan diskusi arsitektur yang relevan menggunakan vector embeddings

### Metafora Inti

| Konsep | Padanan Prism | Deskripsi |
|---------|------------------|-------------|
| 🍳 **Dapur** | Dasbor SaaS | Tempat "Koki" (Pengembang) mencampur bahan (Next.js, Tailwind, Glassmorphism) |
| 📜 **Resep** | Aturan Konteks | File keluaran (mis., `.cursorrules`) berisi instruksi ketat |
| 🍽️ **Pelayan** | Protokol MCP | Mengirimkan Resep segar langsung ke meja IDE |

### Ekstraksi Video-ke-Konteks

**Dokumentasi Otomatis**: Unggah rekaman layar dari alur kerja pengembangan Anda. Prism menganalisis transkrip video menggunakan Azure OpenAI untuk secara otomatis mengekstrak aturan arsitektur, pola pengkodean, dan praktik terbaik menjadi konteks yang dapat ditindaklanjuti oleh asisten coding AI Anda.

Bekerja dengan:
- **Cursor** ✅
- **Windsurf** ✅
- **Claude (via MCP)** ✅
- **VS Code** (via ekstensi MCP)
- **GitHub Copilot** (segera hadir)

Alih-alih berharap AI Anda mengikuti praktik terbaik, **Prism menerapkannya**.

## Mulai Cepat

### Opsi A: Dasbor Web (Direkomendasikan)

```bash
# 1. Daftar di dasbor web
https://prism.syntaxure.dev/sign-up

# 2. Buat proyek pertama dan profil merek Anda
# 3. Unggah video atau buat aturan secara manual
# 4. Ekspor file .cursorrules dan tempel ke proyek Anda
```

### Opsi B: Server MCP (Lanjutan)

Untuk sinkronisasi real-time dengan IDE Anda:

```bash
# 1. Instal server MCP secara global
npm install -g @prism/mcp-server

# 2. Konfigurasi IDE Anda (Cursor/Windsurf/VS Code)
# Tambahkan ke pengaturan MCP Anda:
{
  "mcpServers": {
    "prism": {
      "command": "prism-mcp",
      "args": ["--api-key", "KUNCI_API_ANDA"]
    }
  }
}

# 3. Asisten AI Anda sekarang memiliki akses langsung ke aturan Anda
```

## Apa yang Membuat Prism Berbeda?

### 🎥 Penangkapan Konteks Video-Pertama
Rekam layar Anda sambil mendiskusikan arsitektur. Prism secara otomatis mengekstrak aturan dari penjelasan Anda.

### 🧠 Ekstraksi Aturan Berbasis AI
GPT-4o-mini menganalisis transkrip untuk mengidentifikasi:
- Pola arsitektur
- Konvensi gaya kode
- Aturan penamaan
- Strategi pengujian
- Praktik keamanan

### 🔍 Pencarian Semantik
Embedding vektor memungkinkan menemukan diskusi arsitektur yang relevan, bukan hanya pencocokan kata kunci.

### 🚀 Integrasi MCP Tanpa Konfigurasi
`npx prism connect` dan selesai. Asisten AI Anda sekarang memiliki konteks.

## Contoh Dunia Nyata

```typescript
// Sebelum Prism: Kode generik
const data = await fetch('/api/users');

// Setelah Prism: Menerapkan standar Anda
const { data, error } = await api.users.list();
if (error) {
  toast.error(error.message);
  return;
}
```

Asisten AI Anda belajar dari video Anda bahwa Anda:
- Menggunakan wrapper API kustom dengan penanganan error
- Menampilkan error melalui notifikasi toast
- Mengikuti pola pengembalian awal

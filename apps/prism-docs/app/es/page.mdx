# Prism Context Engine

**El Sistema Operativo de Contexto para Vibecoders** — Elimina la "Contaminación de Contexto" orquestando el flujo de reglas, sistemas de diseño y stacks tecnológicos entre la Nube y los Agentes de IA locales.

## ¿Qué es Prism Context Engine?

Prism Context Engine es una plataforma completa de **gobernanza de contexto impulsada por IA** que:

1. **Extrae Reglas de Video** - Sube grabaciones de pantalla, extrae automáticamente patrones arquitectónicos usando Azure OpenAI
2. **Aplica Estándares** - Despliega reglas a asistentes de codificación AI vía MCP (Model Context Protocol)
3. **Habilita Búsqueda Semántica** - Encuentra discusiones arquitectónicas relevantes usando embeddings vectoriales

### La Metáfora Principal

| Concepto | Equivalente Prism | Descripción |
|---------|------------------|-------------|
| 🍳 **La Cocina** | SaaS Dashboard | Donde el "Chef" (Desarrollador) mezcla ingredientes (Next.js, Tailwind, Glassmorphism) |
| 📜 **La Receta** | Reglas de Contexto | El archivo de salida (ej., `.cursorrules`) con instrucciones estrictas |
| 🍽️ **El Mesero** | Protocolo MCP | Entrega la Receta fresca directamente a la mesa del IDE |

### Extracción de Video a Contexto

**Documentación Automatizada**: Sube una grabación de pantalla de tu flujo de trabajo de desarrollo. Prism analiza la transcripción del video usando Azure OpenAI para extraer automáticamente reglas arquitectónicas, patrones de codificación y mejores prácticas en contexto accionable que tu asistente de codificación AI pueda entender.

Funciona con:
- **Cursor** ✅
- **Windsurf** ✅
- **Claude (vía MCP)** ✅
- **VS Code** (vía extensión MCP)
- **GitHub Copilot** (próximamente)

En lugar de esperar que tu AI siga las mejores prácticas, **Prism las aplica**.

## Inicio Rápido

### Opción A: Web Dashboard (Recomendado)

```bash
# 1. Regístrate en el web dashboard
https://prism.jeffdev.studio/sign-up

# 2. Crea tu primer proyecto y perfil de marca
# 3. Sube un video o crea reglas manualmente
# 4. Exporta el archivo .cursorrules y pégalo en tu proyecto
```

### Opción B: Servidor MCP (Avanzado)

Para sincronización en tiempo real con tu IDE:

```bash
# 1. Instala el servidor MCP globalmente
npm install -g @prism/mcp-server

# 2. Configura tu IDE (Cursor/Windsurf/VS Code)
# Añade a tu configuración MCP:
{
  "mcpServers": {
    "prism": {
      "command": "prism-mcp",
      "args": ["--api-key", "TU_API_KEY"]
    }
  }
}

# 3. Tu asistente AI ahora tiene acceso en vivo a tus reglas
```

## ¿Qué Hace Diferente a Prism?

### 🎥 Captura de Contexto Video-Primero
Graba tu pantalla mientras discutes arquitectura. Prism extrae automáticamente reglas de tus explicaciones.

### 🧠 Extracción de Reglas con IA
GPT-4o-mini analiza transcripciones para identificar:
- Patrones arquitectónicos
- Convenciones de estilo de código
- Reglas de nomenclatura
- Estrategias de prueba
- Prácticas de seguridad

### 🔍 Búsqueda Semántica
Los embeddings vectoriales permiten encontrar discusiones arquitectónicas relevantes, no solo coincidencias de palabras clave.

### 🚀 Integración MCP Sin Configuración
`npx prism connect` y listo. Tu asistente de IA ahora tiene contexto.

## Ejemplo del Mundo Real

```typescript
// Antes de Prism: Código genérico
const data = await fetch('/api/users');

// Después de Prism: Aplica tus estándares
const { data, error } = await api.users.list();
if (error) {
  toast.error(error.message);
  return;
}
```

Tu asistente de IA aprende de tus videos que:
- Usas un wrapper de API personalizado con manejo de errores
- Muestras errores mediante notificaciones toast
- Sigues patrones de retorno temprano

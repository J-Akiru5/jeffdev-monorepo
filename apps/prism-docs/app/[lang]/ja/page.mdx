# Prism Context Engine

**Vibecoders のための Context Operating System** — Cloud とローカル AI エージェント間のルール、デザインシステム、技術スタックの流れをオーケストレーションすることで「コンテキスト汚染」を排除します。

## Prism Context Engine とは？

Prism Context Engine は、以下を実現する完全な **AI パワードのコンテキストガバナンスプラットフォーム** です：

1. **動画からルールを抽出** - 画面録画をアップロードし、Azure OpenAI を使用してアーキテクチャパターンを自動的に抽出
2. **標準を強制** - MCP（Model Context Protocol）を介して AI コーディングアシスタントにルールをデプロイ
3. **セマンティック検索を有効化** - ベクトル埋め込みを使用して関連するアーキテクチャの議論を検索

### 核となるメタファー

| コンセプト | Prism における対応 | 説明 |
|---------|------------------|-------------|
| 🍳 **キッチン** | SaaS ダッシュボード | 「シェフ」（開発者）が材料（Next.js、Tailwind、Glassmorphism）を混ぜ合わせる場所 |
| 📜 **レシピ** | コンテキストルール | 厳密な指示を含む出力ファイル（例：`.cursorrules`） |
| 🍽️ **ウェイター** | MCP プロトコル | 新鮮なレシピを IDE のテーブルに直接届ける |

### 動画からコンテキストへの抽出

**自動ドキュメント化**: 開発ワークフローの画面録画をアップロードします。Prism は Azure OpenAI を使用して動画のトランスクリプトを分析し、アーキテクチャルール、コーディングパターン、ベストプラクティスを AI コーディングアシスタントが理解できるアクションable なコンテキストに自動的に抽出します。

対応ツール：
- **Cursor** ✅
- **Windsurf** ✅
- **Claude（MCP 経由）** ✅  
- **VS Code**（MCP 拡張機能経由）
- **GitHub Copilot**（近日対応）

AI がベストプラクティスに従うことを願うのではなく、**Prism がそれを強制します**。

```bash
https://prism.jeffdev.studio/sign-up
```

### オプション B: MCP サーバー（上級者向け）

IDE とのリアルタイム同期に：

```bash
# 1. MCP サーバーをグローバルにインストール
npm install -g @prism/mcp-server

# 2. IDE を設定（Cursor/Windsurf/VS Code）
# MCP 設定に追加：
{
  "mcpServers": {
    "prism": {
      "command": "prism-mcp",
      "args": ["--api-key", "YOUR_API_KEY"]
    }
  }
}

# 3. AI アシスタントがルールにライブアクセスできるようになりました
```

```
                             │

└─────────────────────────────────────────────────────────────┘
```

## Prism の特徴

### 🎥 ビデオファーストのコンテキストキャプチャ
アーキテクチャについて話し合いながら画面を録画。Prism が説明から自動的にルールを抽出します。

### 🧠 AI パワードのルール抽出
GPT-4o-mini がトランスクリプトを分析して以下を特定：
- アーキテクチャパターン
- コードスタイル規約
- 命名規則
- テスト戦略
- セキュリティプラクティス

### 🔍 セマンティック検索
ベクトル埋め込みにより、キーワードマッチングだけでなく、関連するアーキテクチャの議論を見つけることができます。

### 🚀 ゼロ設定 MCP 統合
`npx prism connect` で完了。AI アシスタントにコンテキストが追加されます。

## 実際の例

```typescript
// Prism 導入前: 汎用コード
const data = await fetch('/api/users');

// Prism 導入後: あなたの標準を強制
const { data, error } = await api.users.list();
if (error) {
  toast.error(error.message);
  return;
}
```

AI アシスタントは動画から以下を学習：
- エラーハンドリング付きのカスタム API ラッパーを使用
- toast 通知でエラーを表示
- early return パターンに従う

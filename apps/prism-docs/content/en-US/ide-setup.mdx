# IDE Setup

Connect Prism to your editor. Write rules once — enforce them everywhere.

## Automatic Setup (Recommended)

```bash
prism init
```

Run this once after installing the CLI. It:
- Detects which editors you have installed
- Writes the correct MCP config for each
- Prints a summary of what was configured

Then **restart your editor** — Prism is connected.

---

## Manual Setup by IDE

### Cursor

Create `.cursor/mcp.json` in your **project root** (or `~/.cursor/mcp.json` for global config):

```json
{
  "mcpServers": {
    "prism": {
      "command": "prism",
      "args": ["serve"],
      "env": {
        "PRISM_API_KEY": "pk_live_YOUR_KEY_HERE"
      }
    }
  }
}
```

Restart Cursor. The AI will automatically call Prism on every prompt.

**Where to get your API key:** Dashboard → Settings → API Keys → Generate Key (Pro plan required)

### VS Code

1. Open VS Code
2. Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
3. Type **"Preferences: Open User Settings (JSON)"** and select it
4. Add inside the root `{}` of your `settings.json`:

```json
{
  "mcp": {
    "servers": {
      "prism": {
        "type": "stdio",
        "command": "prism",
        "args": ["serve"],
        "env": {
          "PRISM_API_KEY": "pk_live_YOUR_KEY_HERE"
        }
      }
    }
  }
}
```

5. Save and restart VS Code

**VS Code Extension (optional but recommended):**

The Prism VS Code extension adds:
- Diagnostics on save (rule violations highlighted)
- Quick-fix code actions (`prism_fix` applied with one click)
- Sidebar tree view for projects and rules
- Status bar showing connection state

Install it from the VS Code Marketplace: search **"Prism Context Engine"**.

### Windsurf

1. Open **Windsurf Settings** → **MCP Servers**
2. Click **Add Server** and fill in:

| Field | Value |
|-------|-------|
| Name | `prism` |
| Command | `prism` |
| Args | `serve` |
| Env Key | `PRISM_API_KEY` |
| Env Value | `pk_live_YOUR_KEY_HERE` |

3. Save and restart Windsurf

### GitHub Copilot (VS Code)

Add a `.github/copilot-instructions.md` file to your project. Prism can export rules to this format:

In the dashboard → your project → **Export Rules** → select **"GitHub Copilot"**.

Then drop the exported file into `.github/copilot-instructions.md` in your repo root.

> [!NOTE]
> GitHub Copilot does not natively support MCP servers as of 2026. The export approach gives you Copilot compatibility without live sync.

## What `prism serve` Does

When your IDE starts `prism serve`, it:

1. Checks if `PRISM_API_KEY` is valid (calls Dashboard `/api/api-keys/verify`)
2. Spawns `prism-mcp-server --standalone` as a child process
3. Sets up a transparent stdio relay between your IDE and the MCP server
4. Falls back to a local lite server (offline mode) if Cosmos DB is unreachable

The MCP server exposes 9 tools to your AI:
- `get_architectural_rules` — Smart-ranked rules for any task
- `prism_scan` — Playwright URL extraction
- `get_skill` — Procedural guides on demand
- `prism_check` / `validate_code` — Code validation
- `prism_fix` — Auto-correction
- `repo_extract` — AI rules from repo scan
- `search_video_transcript` — Beta video search
- `validate_code_pattern` — Pattern matching

## Offline Mode

If you don't have an API key or are working without internet:

```bash
prism serve --offline
```

This serves rules from `~/.prism/rules/rules.json` (generated by the last `prism sync`) using keyword-based ranking instead of Gemini embeddings. 8 of the 9 tools are available.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `prism: command not found` | Re-run `npm install -g @prism-engine/cli`, restart terminal |
| `API key invalid` | Generate a new key: Settings → API Keys |
| `No rules returned` | Run `prism sync` to download your rules |
| IDE shows MCP error | Run `prism doctor` to check all systems |
| Rules are stale | `prism sync` then restart the MCP server in IDE settings |
| `prism serve` crashes | Check Node ≥ 20: `node --version` |

Run `prism doctor` for a full health check with actionable fixes.

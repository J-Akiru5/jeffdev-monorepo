# Prism Context Engine

**El Sistema Operativo de Contexto para Vibecoders** — Elimina la "Contaminación de Contexto" orquestando el flujo de reglas, sistemas de diseño y stacks tecnológicos entre la Nube y los Agentes de IA locales.

## ¿Qué es Prism Context Engine?

Prism Context Engine es una plataforma completa de gobernanza de contexto impulsada por IA.

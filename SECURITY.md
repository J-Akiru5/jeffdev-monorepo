# Security Policy

## Supported Versions

We actively support and patch the latest version of our applications.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of our services seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues. Instead, follow these steps:

1. Send an email to **security@jeffdev.studio** with details of the vulnerability.
2. Include steps to reproduce, potential impact, and any proof of concept (PoC) code or screenshots.
3. We will acknowledge your report within 48 hours and coordinate a fix.

Please do not disclose the vulnerability to third parties or the public until we have released a patch or determined that it does not pose a threat. Thank you for helping keep our software secure!

Paired Token Trial: Prism-enforced vs unenforced

N = 3 tasks · paired sessions on real Claude Code 2.1.278 (claude-sonnet-5) · transcripts saved alongside this report · every figure parses directly from a JSONL file — no estimates

1Method

Three short component tasks, each run as a baseline session (no Prism hook; a simulated human reviewer catches the violation in a second user turn) and an enforced session (Prism PostToolUse hook active in .claude/settings.json; the agent self-corrects in the same turn after the hook blocks the write with exit-2 + exact fixes). Same starting repo state, same task prompt. The rule of record is the demo's own: forbidden_pattern #[0-9a-fA-F]{6}\b + semantic (Gemini) layer for non-hex equivalents, via the project's .prism/rules.json.

  • T1 — WarningBanner.tsx: brand red #ef4444 (regex-class catch)
  • T2 — CtaButton.tsx: brand primary #06b6d4 (regex-class catch)
  • T3 — InfoPill.tsx: rgb(6, 182, 212) — the rgb() equivalent of #06b6d4 (semantic-class catch; regex alone cannot see it)

4What this does — and does not — prove

Directional evidence, N = 3 paired tasks — not a statistical study. The one number that is consistent and unambiguous across every task is the human round-trip count: 2 → 1. The unenforced path always requires a human to notice, message the agent, and wait; the enforced path resolves in the agent's own turn. The raw-token totals are mixed: inline enforcement was clearly cheaper in T2 (−18% to −40%), roughly a wash in T1 (+5%, one extra model call in the block-retry loop), and more expensive in T3's compliance arm (+28%, the agent read the constitution proactively) — while T3's quota-starved arm shows the fail-open cost of relying on a rate-limited semantic layer (violation silently survived).

Caveats, stated plainly: cache_read tokens dominate every session (85–92% of the total) because each model call re-reads the full context — and cache reads are billed at a heavy discount (0.1×), so raw-token deltas overstate cost deltas. The reviewer beat in T2 also shows the unenforced path is not merely slower but sometimes fails entirely (the agent refused an unverifiable human claim). The T3 semantic catch is network- and quota-dependent (free tier: 20 req/min for gemini-3.6-flash); its failure mode is fail-open by design, which this trial reproduced twice.

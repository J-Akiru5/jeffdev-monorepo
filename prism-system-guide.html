01 The Big Picture

What is Prism?

One sentence, plain English.

💡 The Simple Version

Prism is a product that lets developers store their coding rules in a website, and then feeds those rules directly into AI coding assistants (Cursor, VS Code, Claude, Windsurf) — so the AI always follows the rules instead of guessing.

🧠

The Website

apps/prism-engine

Where users log in, create projects, write rules, see analytics, get API keys.

🤖

The AI Connector

apps/prism-mcp-server

Talks directly to AI assistants. Reads rules from the database and feeds them to the AI.

⌨️

The Installer

packages/prism-cli

The prism terminal command. Connects the website to the AI assistant on the user's computer.

↑ These 3 things all share the same database. That's the whole system.

http://localhost:3001

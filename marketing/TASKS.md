## How to Use This with GitHub Projects

```bash
# 1. Create a new GitHub Project (Board layout)
gh project create "Marketing" --owner J-Akiru5 --format json

# 2. Create issues from tasks (example)
gh issue create --title "[P1-HIGH] Create LinkedIn company page" \
  --body "Owner: Mark. Phase 1. Create and optimize LinkedIn page with logo, banner, tagline." \
  --label "Phase-1,Priority-High,Owner-Mark,marketing"

# 3. Add issues to project board
gh project item-add <project-number> --owner J-Akiru5 --url <issue-url>

# 4. Or use GitHub's CSV import for bulk creation
```

### Recommended GitHub Project Fields

| Field | Type | Values |
|-------|------|--------|
| Status | Select | Backlog, Ready, In Progress, In Review, Done |
| Priority | Select | High, Medium, Low |
| Phase | Select | Phase-1, Phase-2, Phase-3, Ongoing |
| Owner | Select | Mark, Jeff, Lou, Karl, Hazel |
| Effort | Select | S (1-2h), M (half day), L (1-2 days), XL (week) |
| Platform | Select | LinkedIn, Twitter, YouTube, Blog, Website, Discord, GitHub |
| Type | Select | Content, Design, Development, Outreach, Analytics, Ops |
